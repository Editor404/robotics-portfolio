# Evidence originals

This directory contains public, project-level evidence files for portfolio projects that do not have a dedicated GitHub URL in their original course/project folder.

## Included

- `on-device-ai/`: model-training notebook, team report, training history, and lane-navigation `.h5` weights for the Raspberry Pi vision autonomous driving project.
- `atmega-smart-trash-bin/`: ATmega128 firmware source and hardware demo videos for the sensor/motor control project.
- `cpp-computer-vision/week7-source/`: original Qt/C++ source files for Canny, Harris, Hough, histogram, and UI integration.
- `robot-kinematics-dynamics/`: MATLAB symbolic dynamics source (`middle.m`).
- `convnext-otitis-ct/`: PyTorch model/inference source, validation CSV, and a redacted report copy.

## Excluded intentionally

- Course lecture PDFs/manuals and unrelated reference packages.
- Large generated archives and model artifacts over practical GitHub size limits, such as `best_model.pth` and submission ZIP files.
- Files containing student ID or unnecessary personal identifiers unless a redacted copy is provided.
