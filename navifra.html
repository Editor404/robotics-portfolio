나비프라에 맞춘 대표 프로젝트

1. 로봇프로그래밍 자율주행 시스템

전체 시스템 설계와 모터제어, SLAM 맵 생성, 전역 Path Planning 결과를 실제 자율주행 동작으로 연결한 경험입니다. 물류 AMR 개발에서 중요한 맵-경로-제어 통합 관점과 직접 연결됩니다.

2. Raspberry Pi 온디바이스 비전 자율주행

차선 추종 CNN과 객체 인식 YOLO를 비동기 구조로 분리하고 FSM으로 모터 명령을 결정했습니다. 제한된 컴퓨팅 환경에서 주행 루프를 안정화한 경험입니다.

3. Window AI Robot

ROS2 기반 분산 노드, 카메라 좌표 변환, IMU/압력 센서, 하위 MCU 제어를 하나의 로봇 시스템으로 통합했습니다.

4. C++ 컴퓨터비전 알고리즘

라이브러리 호출에만 의존하지 않고 영상처리 알고리즘 내부 원리를 C++로 구현했습니다. 자율주행 인지 모듈 디버깅과 성능 개선의 기반이 됩니다.

지원 메시지

나비프라가 지향하는 물류 로봇 자율주행 S/W는 현장 환경에서 정확한 위치 추정, 안전한 경로계획, 안정적인 모터제어, 그리고 실제 로봇 적용 후의 반복 개선이 중요하다고 이해합니다. 저는 신입으로서 기존 자율주행 모듈의 구조를 빠르게 이해하고, 재현 가능한 테스트와 현장 이슈 분석을 통해 C++/Linux 기반 로봇 S/W 개발에 기여하겠습니다.
